# CamoGED 专著出版工作计划

## 书名

**《伪装：生成、识别与评价——自然、战争与机器的跨域综观》**  
*Camouflage: Generation, Detection, and Evaluation—Across Nature, War, and Machines*

## 1. 文档性质

本文件是出版工作计划，不是事实来源，也不承担项目宣传。关于选题差异、已有著作和“尚未发现同类专著”等判断，应以 `BOOK_SEARCH_METHODOLOGY.md` 的检索范围、截止日期和 `BOOK_FACTCHECK_REGISTER.md` 的核验记录为准。

本书定位为：

> 一部跨学科研究专著及其可执行附录，使用“隐藏方—揭示方—评价者”作为工作性分析语言，比较不同领域中观察者、信道、任务、协议和失败模式的结构相似性。

该框架不是已完成的统一博弈论，也不意味着自然、军事、艺术和机器视觉具有相同机制或历史因果。

## 2. 目标读者

- 生物学、视觉生态与知觉研究者；
- 材料、传感器、视觉文化和安全研究者；
- 计算机视觉与机器学习研究者；
- 需要理解评价协议、数据治理和复现边界的研究生与工程人员。

本书不承诺成为模型手册、实时SOTA数据库或现实部署指南。动态元数据、软件接口和研究项目状态由仓库其他组件维护。

## 3. 结构

全书四篇十六章：

1. **伪装的前世今生**：定义、自然机制、军事史与视觉文化；
2. **生成**：物理材料、物理对抗、数字隐藏与学习式生成；
3. **识别**：传感器、数据协议、图像、视频、实例、语义与基础模型；
4. **评价**：统一报告逻辑、指标边界、前沿与伦理。

附录承担数据登记规则、指标速查、报告模板、术语、检索方法、项目状态和图像版权清单。

`coder`、`flowcamo`、`dualvcod` 在可复现论文版本形成前仅作为研究议程，不占用正式方法篇幅，不预填结果。

## 4. 章节验收模板

每章依次完成：

1. 导读与本章问题；
2. 证据和方法主线；
3. 必要案例或教学示意；
4. 局限、争议和不可外推范围；
5. 单一小结；
6. 延伸阅读。

验收要求：

- 关键事实由一手来源或权威综述支持；
- “首次、最大、最强、当前”等用语有检索范围和日期；
- 教学代码明确标为示意，不被当作真实实验；
- 数据、指标和软件状态与机器可读来源一致；
- 不在小结后追加第二轮结论；
- 军事和对抗内容遵守 `ETHICS.md`。

## 5. 证据与事实核查

证据按以下层级记录：

- **P**：一手论文、标准、档案和官方文件；
- **S**：权威专著与系统综述；
- **T**：预印本、项目页和临时技术资料。

历史“首次”、数据集规模、许可证、方法发表状态和正式性能比较至少需要一条可核验来源。开放问题进入 `BOOK_FACTCHECK_REGISTER.md`，不得由编辑推测补全。

## 6. 图像与版权

正式发行版中的每幅外部图像必须登记：

- 文件和图号；
- 作者或机构；
- 原始来源；
- 许可或授权；
- 是否改绘；
- 署名文本；
- 最后核验日期。

无法确认许可的动物摄影、艺术作品、军事照片、数据集样例和历史图片不得进入发行版。优先使用公版、开放许可、作者授权或原创图示。

## 7. 代码和数据

- 书中代码单元用于解释概念，默认不构成方法有效性证据；
- 可复现结果必须记录数据版本、随机种子、依赖和预期输出；
- 正文不手工维护易漂移的排行榜数字；
- 数据集和论文元数据由 `data/*.yaml` 提供导航，但正文事实仍须引用原始文献；
- 标准指标只使用通过验证的实现，实验性替代必须显式标记 `_lite` 或“教学示意”。
